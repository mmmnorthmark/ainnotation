# Security Policy

AInnotation is an **unofficial, unsupported code sample published for learning
purposes only** (see the disclaimer in the [README](README.md) and the
[LICENSE](LICENSE)). It is not a product, has no maintenance or support
commitment, and is not affiliated with or supported by Tableau or Salesforce.

## Supported versions

None. No version of this sample is supported or actively maintained, and no
security patches are guaranteed.

## Reporting

Because this is an unsupported example, there is **no security response process
and no service-level commitment**. You are welcome to open a GitHub issue to note
a problem for other readers, but please do **not** expect a fix, a response, or a
disclosure timeline.

Do not report issues affecting Tableau or Salesforce products here — this
repository is not an official channel for either. Report those through the
appropriate official Tableau/Salesforce security channels instead.

Use this code, and anything derived from it, entirely at your own risk.
